## ⚖️ Third-Party Software Redistribution Policy

- Proprietary software, warez, or cracked software are **STRICTLY PROHIBITED** in this repository.
- If a technician requires proprietary software (e.g. specialized hardware vendor diagnostic utilities), the toolkit provides a downloader script (`Scripts/PluginManager.ps1`) or allows placing executables manually in `PortableApps/` without distributing proprietary binaries.

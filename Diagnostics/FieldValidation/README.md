# Field Validation Telemetry & Test Record Store

This directory stores physical hardware validation test run records generated by `Scripts/HardwareValidation.ps1`.

---

## 📂 Subdirectory Format

Each physical hardware validation run produces a folder named after its Test ID:

```text
Diagnostics/FieldValidation/
└── UT-FIELD-001/
    ├── machine.json    <- Hardware & firmware inventory metrics
    └── result.json     <- Comprehensive test run results & safety log
```

---

## 🔒 Privacy Rule

Field validation JSON reports contain hardware metrics (CPU, RAM, storage model, BIOS version, firmware mode). No user credentials, passwords, or recovery keys are ever recorded.
